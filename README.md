## Descripción del Taller
Este repositorio contiene la solución completa en Java para el taller de estructuras lineales y matrices. El proyecto está diseñado de forma modular utilizando paquetes orientados a objetos:

* **arreglos:** Implementación de ejercicios con vectores unidimensionales.
* **matrices:** Operaciones y lógica de programación con arreglos bidimensionales.
* **arraylist:** Colecciones dinámicas y manejo de objetos (Partido.java).
* **Main.java:** Menú principal que integra y ejecuta todos los ejercicios del taller.
